# 記帳系統說明

> 本文件根據 `記帳系統.drawio.svg` 流程圖整理而成。

## 系統架構總覽

整個系統分為三大模組，使用者透過 Telegram 操作，資料最終儲存於 Google 試算表。

```
使用者 ──► Telegram Bot ──► 資料儲存 (Google 試算表)
```

---

## 一、使用者流程

| 步驟 | 說明 |
| --- | --- |
| 1. 建立身份 | 註冊／辨識使用者 |
| 2. 建立帳本 | 為使用者建立帳本 |
| 3-1. 登記入帳 | 記錄收入 |
| 3-2. 登記支出 | 記錄支出 |
| 4. 傳遞給 Telegram | 將紀錄送往 Telegram |

## 二、Telegram

| 步驟 | 說明 |
| --- | --- |
| 1. 接收使用者資訊 | 接收來自使用者流程的資料 |
| 2. 建立帳本 | 建立／對應帳本 |
| 3. 登記明細 | 寫入明細並送往資料儲存 |

## 三、資料儲存

| 步驟 | 說明 |
| --- | --- |
| 1. 建立 Google 試算表 | 作為後端儲存 |
| 2. 發送 API | 透過 API 寫入資料 |
| 3. 紀錄事件 | 記錄交易事件 |

## 完整記帳流程

```
記帳
  └─ 選擇進出（支出／進帳）
       └─ 選擇帳本（帳本一～五）
            └─ 選擇類別（食衣住行育樂）
                 └─ 選擇子類別
                      └─ 選擇支付方式（現金／Line Pay／支付寶／信用卡…）
                           └─ 寫入 Google 試算表
```
